## What it's for
The API key lets your receptionist app run calls and buy numbers on your Telnyx account. The wizard checks it with Telnyx and shows your credit before saving it.

## Steps
1. In Telnyx, click your profile icon (top right), then **Account Settings**, then **API Keys**.
2. Click **Create API Key** (top right).
3. Give it a name, for example "Receptionist".
4. Under **Expiration**, leave it on **No Expiration**.
5. Create the key and copy it straight away.

## What to paste into the wizard
The whole key, on one line. It starts with `KEY`.

## Permissions / scopes
None to choose. A Telnyx API key works across your whole Telnyx account.

## Watch out for
- Telnyx shows the full key only once. If you lose it, create a new one.
- Anyone with the key can spend your Telnyx credit. Paste it only into the wizard, never into an email or chat.
- Finish the upgrade and add credit first ("Create and upgrade your Telnyx account"). Until you do, real callers can't get through.
- If you set an expiry date by mistake, the receptionist stops working on that date. Create a new key with **No Expiration**.
- Use a key from the same Telnyx account every time. Your numbers and receptionists live in that account.
- The `KEY` prefix comes from Telnyx's own examples. Telnyx doesn't promise every key will look like that, so if yours doesn't, paste it anyway.
