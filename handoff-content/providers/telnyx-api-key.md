---
id: telnyx-api-key
title: Copy a Telnyx key
time: 1 minute
cost: Free
link: https://portal.telnyx.com/#/api-keys
---
1. Open [API Keys](https://portal.telnyx.com/#/api-keys).
2. Click **Create API Key**.
3. Copy the key (starts with `KEY`).
4. Paste it here.

> **Stuck?** Rejected? Copy the whole key again.
