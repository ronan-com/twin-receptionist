id: vapi-account
title: Vapi keys
time: 5 minutes
cost: Free to open. Calls are billed per minute.
link: https://dashboard.vapi.ai/
---
1. Sign up at [dashboard.vapi.ai](https://dashboard.vapi.ai/) and add credit under **Billing**.
2. Open [API Keys](https://dashboard.vapi.ai/org/api-keys).
3. Copy the key under **Private API Keys**.
4. Copy the key under **Public API Keys**.

> **Stuck?** Rejected? The private key is the one under **Private API Keys**.
